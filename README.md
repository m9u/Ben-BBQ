# Ben's BBQ Decider

Ben has a hard time deciding whether to BBQ or not. This tool helps.

## What it does

A single-page app that gives Ben everything he needs to make the big call:

- **Coin flip** — the ultimate decision-maker. Heads = BBQ on, tails = stay inside.
- **Amsterdam weather** — 7-day forecast so Ben can see if the weather is actually on his side.
- **BBQ calculator** — works out quantities (meat, sides, drinks) based on guest count.
- **Grill timer** — modal countdown timer so nothing gets burnt.
- **Live radar** — real-time rain radar for Amsterdam. No surprises.
- **Albert Heijn deals** — checks this week's AH bonus for coal and beer deals.

## Usage

Open `index.html` in a browser. No build step, no dependencies, no server needed.

## Stack

Plain HTML, CSS, and JavaScript. Uses:
- [Open-Meteo](https://open-meteo.com/) — free weather API
- [Albert Heijn Bonus API](https://www.ah.nl/bonus) — weekly supermarket deals
- [Buienradar](https://www.buienradar.nl/) — Dutch rain radar embed
